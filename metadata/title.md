# Title selection — Null Sector

Ten candidates; selected by the composer for this independent draft. No title choice implies an audition result.

| Candidate | Direction |
| --- | --- |
| Null Sector | A machine patrol traverses an unlit sector. Its pulse never stops; isolated signals mark doors, turns and the final seal. |
| Blind Address | A narrow mechanical operation under pressure. |
| Dark Port | A stable state with an unsettling implied fault. |
| Empty Bus | A terse instruction with audible rhythmic implications. |
| Ghost Register | An enclosed technical environment. |
| Quiet Watch | A timing relationship capable of driving a motif. |
| Unlit Node | A compact name for a persistent operating condition. |
| Sector Zero | A limit approached without a conventional breakdown. |
| Cold Access | A signal whose state can be heard changing. |
| Vacant Signal | A hard-edged technical phrase suited to a decisive coda. |

## Winner: Null Sector

Dark surveillance electro: continuous kick/bass movement under widely spaced, low bell messages and dry access clicks.

A machine patrol traverses an unlit sector. Its pulse never stops; isolated signals mark doors, turns and the final seal.

# Structural arc and motifs — Null Sector

A machine patrol traverses an unlit sector. Its pulse never stops; isolated signals mark doors, turns and the final seal.

A defines the patrol and its unanswered messages. B crosses G and A to return to B. C brings the bell replies closer while the bass keeps the same deliberate stride. The order returns through alternate access routes, then a single D group closes the sector with a spaced B-minor seal.

Tonal language: B minor; G and A are adjacent access routes.

| Motif | Identity |
| --- | --- |
| Patrol motor | A steady kick floor with syncopated TuneBass steps; never a drumless passage. |
| Access ping | Low ExBells notes in separated pairs, answered across a phrase rather than crowded into runs. |
| Door state | KorgFilter flashes at chosen bar heads, followed by WoodBlock or SynClaves access ticks. |
| Seal sequence | Three separated low impacts and a final B message replace a conventional fade. |

## Phrase vocabulary

These are authored thirty-two-row melodic fragments. Pattern tables are the build source. A fragment may hand its reply to another sample as described in the pattern notes; each event is still one note. Times below are decimal row offsets.

| Fragment | Events: row / trigger |
| --- | --- |
| a | 02/B-3, 12/F#4, 22/D-4 |
| b | 04/A-3, 14/C#4, 24/B-3 |
| c | 00/G-3, 10/B-3, 22/D-4, 28/B-3 |
| d | 03/A-3, 13/C#4, 23/E-4 |
| e | 02/B-3, 08/D-4, 14/F#4, 24/E-4, 29/D-4 |
| f | 00/F#3, 10/A-3, 20/C#4, 28/E-4 |
| g | 01/D-4, 09/C#4, 17/B-3, 27/F#3 |
| h | 04/F#4, 12/E-4, 20/D-4, 28/B-3 |

The named motif is developed by changing which fragment answers it, the underlying bass state, and the percussion handoffs. The first group begins with the complete working ensemble. Repeated groups return at full identity; there is no default empty breakdown and gradual rebuild. The terminal group is used once, and its coda has separately authored events.
